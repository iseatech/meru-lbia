STEP 1 — DATABASE

	•	user_id UUID not null
	•	service_type TEXT not null
	•	verification_code TEXT unique not null
	•	pdf_sha256 TEXT not null
	•	created_at TIMESTAMPTZ default now()
	•	status TEXT default ‘valid’

Add an index on verification_code.

Do not modify any existing table.

STEP 2 — VERIFICATION CODE GENERATION

Create new file:

server/security/documentIntegrity.ts

Implement function:

generateVerificationCode(input: {
briefId: string
userId: string
serviceType: string
})

Format:

MERU-YYYYMMDD-HHMMSS-XXXXXXXX

Where XXXXXXXX is the first 8 uppercase characters of:

SHA256(briefId + userId + timestamp + serviceType)

Use UTC time.

STEP 3 — PDF HASHING

	1.	Compute SHA-256 hash of the PDF buffer.
	2.	Store hash in pdf_sha256 field.

If storage fails, PDF generation must still succeed.
